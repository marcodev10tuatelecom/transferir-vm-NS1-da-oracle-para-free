# Security policy

Não abrir issue/PR contendo segredo real. Se um segredo aparecer no Git público, trate como comprometido: revogue/rotacione primeiro e só depois limpe histórico.

Dados proibidos: private keys, TSIG, publisher password, token, PSK, credenciais cloud, senha de banco e dumps contendo autenticação.

O repositório contém exemplos e nomes públicos de serviços; isso não concede autorização para expor endpoints administrativos.
